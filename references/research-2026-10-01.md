# 同类 Skill 与真实产品模式调研

核对日期：2026-10-01。本轮读的是公开 Skill 源文件、官方产品文档、设计系统示例和标准说明；未登录 Linear、GitHub 或 Vercel 产品执行真实业务，也未把文档截图当成已测量的线上 UI。移动分支和活文档可能变化，下列链接是本次参考入口，不声称是永久快照。

## 来源、采纳和边界

| 来源 | 读到的模式 | 本仓库采用／不采用 |
|---|---|---|
| [Anthropic frontend-design](https://raw.githubusercontent.com/anthropics/skills/main/skills/frontend-design/SKILL.md) | 从主题与内容建立身份，排版与结构有理由，克制重复装饰 | 用任务决定视觉重点；不复制其文案或把某种字体、颜色一律列为禁用 |
| [Impeccable 当前入口](https://raw.githubusercontent.com/pbakaus/impeccable/main/skill/SKILL.src.md) | 按表面用途和任务加载参考；优化保留身份，重设计改变视觉方向 | 采用按需细节与有限复核；不引入其 CLI、二进制、hooks、自动治理文件或评分仪式 |
| [Vercel web-design-guidelines Skill](https://raw.githubusercontent.com/vercel-labs/agent-skills/main/skills/web-design-guidelines/SKILL.md) | 读取源码并以文件位置报告检查发现 | 保留位置、状态、后果；不使日常使用强依赖每次联网抓取远程指令 |
| [Vercel Web Interface Guidelines](https://vercel.com/design/guidelines) | 焦点、数字排版、链接行为、稳定占位、动效等细节 | 采用适用的细节；不照抄“所有状态深链”、禁缩放设置或未实测延迟预算 |
| [Linear Filters](https://linear.app/docs/filters) | 主要筛选反映到 URL，部分视图／快速筛选不包含 | 区分可分享状态和短暂状态；不将所有显示选项持久化到 URL |
| [Linear Display options](https://linear.app/docs/display-options) | 筛选与展示字段不同；个人偏好和工作区默认不同 | 显示范围与写入影响范围明确，不擅自修改其他成员的默认视图 |
| [GitHub Primer DataTable](https://primer.style/product/components/data-table/) | 密度、排序、分页与加载占位各有独立模式 | 补数值排序、范围说明与窄屏比较；不为少量记录安装 React 或虚拟列表 |
| [GOV.UK Error summary](https://design-system.service.gov.uk/components/error-summary/) | 摘要链接字段，文案匹配，键盘定位 | 适配长表单恢复；该系统“总是展示摘要”的规则不机械推广到所有 UI |
| [GOV.UK Validation](https://design-system.service.gov.uk/patterns/validation/) | 校验说明如何纠正并帮助用户继续 | 区分字段校验与网络失败，不清空合理输入 |
| [WAI-ARIA 可排序表格示例](https://www.w3.org/WAI/ARIA/apg/patterns/table/examples/sortable-table/) | 原生 table、表头按钮和 aria-sort | 对应样张的语义结构；APG 示例不是直接可用的全站合规证明 |
| [MDN InputEvent.isComposing](https://developer.mozilla.org/en-US/docs/Web/API/InputEvent/isComposing) | 标识事件是否发生在组词过程中 | 补中文输入边界；合成事件验证不等于各平台实体输入法验证 |
| [MDN History API](https://developer.mozilla.org/en-US/docs/Web/API/History_API/Working_with_the_History_API) | push、replace 与 popstate 的区别 | 补返回／恢复契约；样张不写历史，不声称已验证真实路由 |
| [W3C Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html) | 320 CSS px 的重排条件与必要二维内容例外 | 表格局部滚动，外层仍重排；不把窄视口当实体缩放测试 |
| [W3C Text Spacing](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html) | 用户覆盖间距后不能丢内容或功能，适用语言有例外 | 增加间距压力测试；不把测试值改为全站默认排版 |

## 独立判断

外部规范之间存在不同前提。例如 Vercel 页面同时列出移动输入禁缩放的替代写法与尊重缩放的要求；本仓库保留用户缩放，不能复制 `maximum-scale=1`。其深链建议也需受隐私与路由语义约束。品牌大小写、占位符省略号、默认阴影层数等不属于普适标准。

保留本项目的黑白灰与辅助玻璃，不借“避免模板”之名换掉已经指定的视觉。借鉴的是对象层级、密度、失败恢复和输入行为，不是临摹其他品牌或安装它们的整个工具链。没有移植外部实现代码或大段 Skill 文本。
