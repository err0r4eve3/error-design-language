# 连续导航：分栏、返回位置与键盘归属

仅用于反复切换对象、查看详情或有多层局部界面的任务。不是把文章、表单或所有工作台变成聊天软件。参考 Telegram Web A 的具体实现，来源与不采用项见 [研究记录](research-2026-10-01-round9.md)；集合语义沿用 [集合工作流](collection-workflows.md)。已有路由、确认稿与可访问组件优先。

## 布局状态不等于业务状态

把当前对象 ID、查询确认值、筛选、排序、批量选择与当前显示的面板分别管理。窗口从宽变窄，只改变呈现方式，不能清空选择、重读数据、换掉当前对象或把输入草稿当成确认查询。切换账户／权限则必须隔离原数据；不能以保留上下文为由显示前一账户内容。

宽屏可同时显示集合和详情；窄屏有两种合法选择：需要连续比较时保留同屏关系和局部滚动；以单对象阅读为主时，可进入有明确返回入口的详情视图。后者是可返回的导航状态，不是删掉集合功能或隐藏费用列。任务兼有比较需求时，提供“同时查看清单”等真实入口，保留原 DOM／状态或由已有路由可靠恢复。不要强制所有小屏都叠成长页，也不要强制全部改成单栏路由。

隐藏非当前面板时同步处理可访问性和焦点；仅 transform 移出屏幕仍可能留下可聚焦控件。宽屏并排的非模态区域不设焦点陷阱。缩窄时焦点若将被隐藏，移入当前详情；若仍在可见的主题控件等位置，不抢焦点。窗口变宽后仍是同一对象，不能机械重播另一宽度下的滚动坐标。

## 返回不是只让面板消失

显式进入详情前，保存当前集合身份、可见对象／位置锚点、局部滚动位置和合理的返回控件。优先稳定对象 ID，而不是“第 12 行”。关闭或返回时先恢复布局，再恢复阅读位置与焦点；焦点环必须在可见区域内，不落在隐藏按钮、页顶或被固定栏挡住的元素上。

内容与排版未变时，可恢复滚动坐标；存在分页、插入或高度变化时，优先由稳定锚点和相对偏移恢复。锚点删除、筛掉或无权访问时选择仍有效的邻近对象或集合入口，不把旧数值硬塞回页面。若无法精确保留原位置，至少让当前返回对象可见，说明局限，不宣称完整锚点恢复。

用户在详情内查看下一项后，返回目标绑定正在查看的对象，而不是最初点击的行号。仅改变筛选导致详情失效时，不主动跳转焦点或滚动到页尾。长内容异步展开、图片加载、表格横向滚动都可能改变返回体验；它们需要真实操作测试，四条静态记录不足以证明长列表行为。

原生浏览器的 Back／Forward 是另一份契约。宿主有路由时复用其机制，明确首次直达、后退、前进、重载、链接分享和浮层关闭各恢复什么；不为每次打字或 hover 写历史。不得覆盖宿主的 history.state、制造循环返回或阻止用户前进。只有页内返回的离线样例，必须与浏览器历史支持分开描述。本仓库清单没有接管浏览器历史，也不持久化交互状态。

## 一个按键只完成当前语境的一件事

键盘先让输入法、原生控件和最上层活动界面处理。自定义快捷键检查 composition 生命周期、事件 isComposing、已消费的 defaultPrevented；兼容需要时再处理旧式 229 标记，不能只依赖某一平台的一种信号。编辑器、输入框、原生选择器、组合框或菜单的按键不外泄成页面导航。

Escape 关闭当前可关闭层，不同时关闭详情、取消选择和清空搜索。重复触发不跨越多层。优先使用已有组件库的键盘／浮层管理；小面板使用局部监听即可，不为两个按钮建立全局事件总线。确需层级调度时，最上层先处理，处理后不向下穿透，卸载时注销。

快捷键是可见按钮的补充，动作、禁用条件与按钮一致。上一项／下一项按当前排序计算，不越界循环或改动批量选择。浏览器、辅助技术和编辑快捷键不能被随意占用：例如不要把 Ctrl/Cmd+数字从切换浏览器标签页抢来。需修饰键的快捷键仍须区分额外的 Ctrl/Meta/Shift，避免把读屏组合键误识别。

## 焦点随操作原因决定，不随每次渲染重置

初次“查看详情”可以聚焦标题；在详情中连续按上一项／下一项时，保留仍可用的触发控件，让 Enter 或 Space 能再次执行同方向动作。排序、范围摘要更新或读取完成不等于重新进入详情。不要让共享 render 函数每次都 focus 标题，也不要靠增加快捷键绕过基本键盘路径的问题。

控件到达边界、变为禁用或消失时，选择可解释且仍可见的回退位置。原生 disabled 控件失去焦点后，本样例回到当前标题，不自动聚焦相反方向按钮，以免用户继续按 Enter 时突然反向。需要让不可用操作保持可发现时，才按已有组件契约采用 aria-disabled 并完整拦截事件；不能只改样式。

选择数量或当前对象在不移动焦点时改变，用已有、稳定挂载的简短状态区域通知；通知应含对象／范围，但不朗读整张表，不因每次 render 重复播报，也不为通知抢焦点。已通过聚焦标题告知的变化，不再叠加相同播报。状态区域 DOM 正确不等于已完成实体读屏测试。来源及采用边界见 [第十轮调研](research-2026-10-01-round10.md)。

## 列表呈现与运动保持任务含义

名称、编号、状态和次要说明分角色排版；重要对象名不能因聊天摘要通常截断就一律省略。hover 是暂态，当前查看有稳定的非颜色标记，批量选择由复选框和选中样式表达；三者互不冒充。静态指标不添加手型、涟漪或假箭头。

转场只解释进入／返回或空间关系，不阻挡重复操作、不依赖动画完成才更新对象身份；禁用或减少动效时动作立即可用。使用现有运动变量，避免动画整个长表格或让每个状态变化都滑动。检查快速切换、缩放视口与转场中返回，而不仅是静止截图。截图验收等待布局事件与有限转场稳定，不能拿过渡帧当最终样式。

性能手法按负载采用。先确认列表大小、更新频率和真实瓶颈；少量记录不引入虚拟化、Worker 或复杂状态库。虚拟化需要另验行高变化、焦点、锚点与无障碍语义，不能直接给多行中文表格套固定聊天行高。事件监听器、媒体查询和 ResizeObserver 跟随视图生命周期清理；重新挂载不得留下旧闭包改写新页面。

## 本仓库示例及最小回归

[清单样例](../assets/patterns.html) 在小于 720 CSS px 时提供详情优先与同看清单两种状态；这是样例断点，不是 Telegram 常量或通用规范。它保留筛选、排序、勾选和横向滚动，返回原位置，并在行高已变时把目标入口带回视口。它没有实现任意数据插入后的精确锚点恢复、虚拟列表、浏览器历史或跨会话缓存。

至少走：对上一项／下一项连续用 Enter、Space 激活直到边界，再按一次不反向；首次与末次勾选不推移目标；滚动集合 → 勾选 A → 查看 B → 下一项 → 返回；在详情开启时跨断点缩放；编辑／组词时按 Escape 与快捷键；嵌套控件消费按键后不触发外层；减少动效下操作；重复挂载后缩放。若修改浏览器路由，还必须测真实 Back／Forward／重载，内存 HTML 测试不算。把本地操作、实体设备、真实业务和模型对照结果分别记录。
