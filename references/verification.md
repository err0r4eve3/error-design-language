# 验收与回归场景

按修改范围选择，避免把小改动变成全站检查。视觉问题必须看实际渲染；数据与流程问题必须走对应状态，不能只看默认截图。

## 检查顺序

1. **主任务**：从入口到目标结果走一遍。发现重复入口、丢失选择、意外登录门槛、不能返回等问题时优先修复。
2. **状态**：本次涉及的默认、hover、focus、selected、disabled、loading、empty、error、success；不是每个控件都需要所有状态。
3. **布局**：代表性桌面与 390px 手机；覆盖窄屏时加入 320px；多栏或长文本问题补 768／1024／1440px。用项目支持范围调整，不把这些数值当全部设备证明。
4. **内容压力**：长中文标题、长邮箱／URL、多币种价格、两行按钮、空结果、部分数据失败。
5. **操作与偏好**：用键盘实际走到控件，检查焦点可见且未被遮挡，而非仅测聚焦后的文字颜色；检查弹窗背景不可操作、关闭后焦点返回、触控、减少动态效果、强制颜色与实色 fallback。
6. **工程检查**：运行项目要求的类型、构建与相关测试。只有真实风险需要回归测试时才新增自动化，不写逐字匹配样式实现的测试。

移动页面除受控代码／表格滚动外无意外横向溢出。截图查看文字是否被截、按钮是否够用、关键内容是否挤出首屏。桌面模拟不能证明实体手机键盘、浏览器工具栏或客户端触摸体验。

## 从历史失败提取的场景

| 输入／状态 | 可观察的合格结果 |
|---|---|
| 灰阶显得刺眼 | 大面积背景更柔和；标题、正文、价格和按钮仍清楚 |
| 灰阶缺少层级 | 内容面能辨认，选中项有明确标记，主要操作不与次级项混同 |
| 选中某个学习页面 | 选中前后文字均可读，焦点可辨，未选页面没有同时亮起 |
| 主／次／轻操作并列 | 主操作最明确，次操作不抢主位，禁用按钮不会与可用主操作相似 |
| hover、按下、禁用、处理中 | 读取浏览器最终前景与背景；主按钮不被通用 hover 染浅，忙碌态仍可读且防止重复提交 |
| 账户选择后再选活动 | 两个维度各自分组，同一单选组没有双选假象 |
| 登录失败 | 表单附近显示可理解错误；焦点和输入保留合理，能重试 |
| 模块读取失败 | 明确“暂未读取”与重试入口，不能冒充为 0 或没有记录 |
| 提交后网络超时 | 给出结果未确认状态；有查询／恢复路径，不诱发重复付款 |
| 购买流程中去登录再返回 | 合理保留配置与目标；易变数据重新校验 |
| 移动阅读到底部再返回 | 没有滚动陷阱，能回到列表，筛选／上下文按既有语义恢复 |
| 地理字段缺失但参考页有地图 | 不制造位置；用已知的事件、来源或待核实状态呈现 |
| 游戏封面与博客记录流 | 两者保留各自适合的表达，不能统一改成同一种卡片／表格 |

## 评审优先级

- **阻塞使用**：不可读的选中态、关键路径断开、隐藏主操作、重复提交风险、错误被当成功。先修复。
- **明显摩擦**：找不到错误、返回丢上下文、层级混淆、移动滚动卡住、边框和内边距失衡。与请求范围一致时修复。
- **表现优化**：圆角更统一、玻璃更细腻、动效更顺。前两类处理后再投入。

报告具体页面、触发步骤、用户后果和修改位置；没有发现问题就不制造改动。不要用一个主观综合分数替代证据。对比改前与改后同尺寸、同内容和状态；记录结构、文字、色彩、形状与交互的具体变化，不仅报告“截图已生成”。

## 样张测试的边界

`node --test tests/*.test.cjs` 检查本仓库 frontmatter、资源链接、宿主调用名、CSS 变量、脚本语法、评测数据结构和颜色数学；不是通用规范验证器，也不运行模型。

已具备 Playwright 时运行 `node tests/preview.cjs`。默认加载本地文件；导航被策略禁止时可显式设 `DESIGN_QA_MODE=inline`，内存装载不证明路由或真实资源加载。安装与环境选项见 [README](../README.md)，普通使用不需要安装依赖。

文字对比仅测受控实色背景。读取实际 computed style，并对背景图、渐变、滤镜、透明合成等未覆盖情况拒绝给出通过结论；不将背景色的简单叠加冒充玻璃背后的真实像素。必要输入边界分别对内外相邻色测量；焦点通过真实 Tab 检查轮廓可见与对比。禁用文字的 4.5:1 是样张内部目标，不是 WCAG 对禁用控件的强制要求。

单选、弹窗、失败恢复与防重仅证明本地样张行为；原生模态可让焦点到浏览器工具栏，但不能到被阻隔的页面控件。减少透明、动效及强制颜色为浏览器模拟检查，不证明全部平台的辅助技术行为。独立控件测试不加载 preview.css，以捕获意外依赖全局 reset；长标签必须能在窄容器内阅读。

维护回归用 [行为场景](../evals/README.md) 另行比较模型执行。严格区分已执行、失败、blocked、not_run；不能用 JSON 校验通过替代行为结果。

## 交付表述

```text
已改进：具体页面、问题与结果。
设计取舍：保留什么品牌，调整什么层级／行为。
已验证：实际页面、状态、尺寸、数据来源和工程检查。
未验证：实体设备、真实支付或生产等尚未覆盖的边界。
```

真实登录、支付、注册和生产变更按已有授权边界执行；UI 测试可用明确标注的本地 fixture。测试数据、HTTP 200、构建通过、服务运行分别证明各自层次，不能替代真实任务完成。
