# 维护边界与规则所有者

仅维护本 Skill 时读取，不加入普通页面任务的必读链。入口负责当前要求和范围优先级；本索引解决重复规则的更新归属，不另设一套视觉风格。

## 一条规则有一个主要定义位置

| 规则职责 | 主要定义 | 其他文件如何引用 |
|---|---|---|
| 调用范围、当前要求、权限 | [入口](../SKILL.md) | 工作流只展开执行路径，不改变权限 |
| 视觉问题诊断、增强与降噪 | [视觉校准](visual-calibration.md) | 整页与组件文件给应用场景，不再复制诊断表 |
| 数值、主题配对、材质起点 | [数值与材料](visual-system.md) | 示例可采用具体数值，但不反向升级成通用阈值 |
| 页面内容骨架与跨模块口径 | [页面综合](design-synthesis.md) | 页面案例保留各自对象和统计范围 |
| 行内槽位、组件变体、样式及主题边界 | [组件契约](component-contracts.md) | 集合页只描述组合，不并建组件规范 |
| 请求、草稿／提交、浮层事件与焦点原则 | [交互契约](interaction-contracts.md) | 连续导航只展开导航场景；测试不能自行改写语义 |
| 集合结果、勾选、当前查看对象 | [集合工作流](collection-workflows.md) | 界面模式引用范围，不定义第二种默认选择策略 |
| 分栏切换、返回锚点、连续键盘 | [连续导航](continuous-navigation.md) | 保留页内导航和真实历史的区别 |
| 中文、技术短语、方向及内容压力 | [界面细节](craft-details.md) | 具体布局以真实容器与内容验收 |
| 标题、帮助、反馈的文案边界 | [产品文案](product-copy.md) | 禁止把实现或验收汇报搬进业务内容 |
| 验证层级和完成表述 | [验收与证据](verification.md) | 历史记录只保留对应轮次事实 |

新增或修改规则时先改主要定义，再检查入口与指向它的应用段落。条件完全相同的重复规定改为短引用；必要的局部例外保留并说明原因。不能靠删掉例外来降低字数，也不能只更新一个文件后声称所有自然语言冲突已消除。本轮没有批量重写全部历史规则。

## 规则、样例与模型效果分别记录

[覆盖索引](../evals/coverage.json) 将能力、规则所有者、样例套件与模型场景关联。`model_status` 和 `integration_status` 在源索引中保持 `not_run`；实际结果写进独立运行证据，不用一个布尔值将样例通过升级为模型通过。

执行 `node evals/coverage.cjs` 检查场景漏挂、无效套件、路径与未经运行的成功声明。执行通过只说明索引结构有效。没有独立应用或模型 fixture 的能力在 `gap` 中保留，不用相似的原生组件测试代替框架集成。

新增浏览器入口同时登记 [套件注册表](../tests/suites.json)，并复用 `tests/support/qa-runtime.cjs`。不得再复制输出目录保护、报告写入、浏览器启动或整页样式装载逻辑。主业务断言留在各套件，不能为了复用而隐藏不同页面的语义。

## 本轮尚未闭合的事项

独立模型执行、宿主路由、真实应用的缓存／Portal／多字段表单，以及非控制台的独立基准仍需对应环境与冻结输入。当前没有这些执行结果。统一 Node 入口不等于已验证洁净机器安装或已接通 CI；本轮没有新增依赖、锁文件或自动工作流。
