# 从原则到完整页面

在新建、整页打磨或明确重设计时按需读取；单个控件修复不进入这条流程。本文是本 Skill 的综合判断，不是任何一本书的摘录。证据和阅读范围见 [资料与案例](reading-and-comparison.md)。

## 先写内容骨架，再选视觉手法

把本页写成一句任务、主要对象及其动作、读者需要的证据。用真实字段或明确标注的演示字段排出首屏和下半页；字段不够就保留未知，不能先画四张数字卡片再编指标。主任务也可以是阅读、欣赏或比较，不是每页都必须放一个 CTA。

无确认稿且确有设计歧义时，在内部快速比较两个内容组织方向，按任务选一个即可；不默认生成两套高保真稿，也不要求用户逐步批准。已确认参考图不再自由探索。全站不因这次选定工作台而永久固定为工作台。

| 内容关系 | 可用骨架 | 不能丢失的关系 |
|---|---|---|
| 一组对象的管理 | 集合工具栏 → 原生列表／表格 → 对象详情 | 筛选范围、对象身份、操作对象 |
| 单个对象的检查 | 对象标题与状态 → 核心信息 → 相关记录／次要属性 | 状态依据与时点、下一步、返回位置 |
| 编辑／创作 | 命令区 → 工作画布或正文 → 按需检查器 | 内容占主位、未保存状态、撤销语义 |
| 阅读／研究 | 标题与出处 → 有约束的正文宽度 → 按需目录 | 论证顺序、引用和长内容节奏 |
| 比较／交易 | 同口径选项 → 差异和限制 → 总额及确认 | 单位、计费周期、排除项、风险 |
| 作品／产品展示 | 主体资产或主张 → 具体证据 → 必要行动 | 内容真实性、完整下半页与移动构图 |

这些是关系模型而不是六套必须照抄的模板。按内容组合；没有理由就不用侧栏、统计卡片或图表。

## 建立视觉重点，而不是添加装饰

明确页面第一眼该看什么、接着看什么、暂时不必看什么。通过相对字号、字重、位置、对齐、间距和实色表面建立顺序。强调一个对象时先降低邻近装饰竞争，不必继续放大它。

在现有品牌许可内选一到两个有依据的识别手法，例如精确的数字列、连贯的编辑式标题、具有任务意义的状态轨、真实作品的裁切方式。禁用虚构地图和漂亮曲线来填空；同样，不把 serif、渐变、bento、紫色或大标题本身当缺陷。判断其是否适合内容、是否抢走任务、是否违反已确认方向。

全灰阶不是把所有字变淡。页面背景、辅助壳层、实色内容、选中对象应能区分。玻璃仅在辅助导航和浮层承担材料角色，关闭模糊后层级仍成立。不要为了所谓高级感把正文、价格或错误提示压成低对比小字。

先统一标题、段落、标注、控件、数字的角色和行高，再考虑更换字体。中文行宽不能把英文字符数原封不动换算成汉字数；以实际字体、容器与阅读内容验证。英文负字距不全局套给中文。关键金额与按钮不靠裁切保持整齐。

## 从组件集合变成有节奏的页面

同级内容使用一致规则，但每个独立对象仍须形成清楚的组；一致不是把相邻内容合并成一大片。不同信息任务可以采用不同密度与容器：概览可以是无框指标带，比较用对齐表格，事件用时间列表。不要为了视觉变化随机交替背景，也不要让每节都重复同样的“标题＋三卡片”。

使用局部布局职责：纵向组的父容器负责间距，工具栏负责自然折行，侧栏与主栏按可用空间决定并排还是堆叠。断点来自内容挤压，不是某台设备的名字。先写合理的 min/max 和重排规则，再加必要 media/container query；不强制重写项目现有布局方案。

卡片并非禁止。独立对象、可移动模块或明确的比较项可以有边界；相连文档和同一任务里的小段落通常不必重复围框。移除边界后若对象或可点击区域变得不清晰，应保留必要边界。

## 线条不能代替层级

把页面优先级映射到可见关系：页级标题给出位置，主要数据或工作区承担第一阅读任务，次要记录与元信息退后。不是每个 h2 同时增大，也不机械规定一定要有三张概览卡。

先用接近与对齐分组：标题到所属内容的距离应小于它到上一组的距离。组内紧、组间疏；空间比值是本页调参起点，不是所有产品的硬标准。列表的紧凑行距不应抄给不相干的章节。明暗、字号、位置与面积配合表达角色，不用每项都加粗。

为画布、辅助导航、主要工作面和选中对象定义不同角色；同一角色保持一致。只有确需独立感的区域才给实底或边界。不要把“去卡片”执行成一整页同底同字号，也不要把“更清楚”执行成卡片嵌套、全屏粗黑线或所有模块反色。

保留有用的线：表格追踪、输入边界、分栏拖动、选中与焦点仍可需要边界。优先撤掉段段横线、指标间竖线、每张卡的重复描边；这不是 border:0 的全局禁令。数据密集区域不为降低线条数量而损失可读性。

**去线检查**：在临时 QA 副本中将已标明的装饰分割线设为透明，不改变盒模型、焦点环、输入边界、图表数据线或真实交互。重新看桌面和手机截图：主次和内容归属是否仍清楚？不清楚就修字号、接近关系、实底或布局，而不是把线加粗。此检查不是无障碍合规测试，也不应作为发布样式。

**同级检查**：主卡比背景深、页标题比区标题大，只说明宏观层级；还应分别检查相邻的辅助指标与状态是否黏连。按 [分组与状态辨识](semantic-distinction.md) 查看局部、非颜色线索和跨视图映射，不能只凭整页通过就结束。

**缩略检查**：缩小截图或眯眼看，是否能辨认页标题、主工作面和次要区域？这是评审辅助，不是眼动测量或用户测试。机械检查字号、间距和表面差异只能防回归，不能给美观打自动分数。

正文构图与文案同时检查：[产品文案边界](product-copy.md)。删除多余副标题后应重新检查标题下方间距，不留空段落占位，也不让标题脱离其内容。

## 数字、图表和状态必须相互对得上

为重要指标确定：对象范围、统计窗口、单位、来源／计算方式、数据缺口。全项目概览与筛选后的列表可以不同，但需要标明范围；不能筛掉一半实例后让用户误读概览也是筛选总和。

相同口径的汇总、图表、表格和操作后数量使用同一数据源；不同窗口或独立演示序列分开标注，不能假装相互派生。避免把展示值硬编码在多个地方。增加／删除／更新对象后回归这些依赖。未知状态既不是宕机，也不是在线；未知成本不能计作零。只有部分对象上报时，已知合计应带覆盖范围，而非冒充完整合计。

图表必须有读者问题、单位、时间窗口、可识别刻度或直接标注及文字替代；不为装饰编造趋势。无历史数据就用当前状态或明确的演示序列，不宣称实时。线图的采样点、柱图的聚合区间和缺失值处理写清；不要以不相关的全局日期选择器暗示它控制所有数据。

加载、真正空集合、筛选无结果、部分数据、失败、无权限分别设计。新的本地演示不连接真实账户、不假装请求成功、不生成有交易后果的能力。

## 操作密度与完整性

每一个看起来可操作的元素必须真实响应、明确禁用并解释原因，或改为非交互内容；不放死链接和只弹“成功”的假按钮。新建对象应真正改变本地列表；导出应产生文件；复制要等待实际 API 结果，失败提供可选择的文本。

输入错误保留输入并指向字段；临时服务失败不伪装成字段错误。忙碌状态防重但不把失败后的重试锁死。关闭并重新打开对话框是新的编辑会话，旧会话的迟到结果不得写入新表单或意外创建对象。对话框打开时移动焦点，关闭后返回有效触发点；列表因更新重建后，按稳定对象标识寻找新的返回目标，不能只保留已脱离 DOM 的节点。

触控尺寸、键盘、减少动效与强制颜色检查按当前标准处理。44px 可作为本项目的舒适点击目标起点，不写成 WCAG 2.2 AA 的统一硬性值；2.5.8 的最低值与间距及例外须查原文。原生语义优先，不用 ARIA 掩盖错误的可点击 div。

## 最后做两次有不同目标的检查

**构图检查**：在同尺寸截图上看标题、主要数据、操作、下半页与留白；检查主任务是否被广告式 hero 挤出首屏、对齐是否连贯、不同内容是否有合理节奏。截图存在不等于已经审阅，不用“10/10”代替具体观察。

**完成任务检查**：从入口走到真实的本地结果，再覆盖至少一个相关失败或恢复状态；窄屏继续走同一任务，而不是只截手机首页。检查新增对象后的汇总、筛选、选中与焦点。

响应式图表同时检查文字比例，不能把 SVG 横向压扁后仍声称标签可读。局部滚动不等于页面没有横向溢出：检查绝对定位的隐藏标签是否逃离容器。对放大字距后放不下的金额重排，不用全局隐藏溢出来遮盖。

先修范围内阻塞，再处理显著构图问题。记录剩余限制即可停止，不无限追加功能。一个按新 Skill 制作的页面是应用示例，不是独立基线实验，不能证明它胜过“普通 vibe coding”。
