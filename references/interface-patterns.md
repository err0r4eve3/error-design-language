# 搜索、表格与反馈模式

适用于列表、控制台、账户、订单和长表单。只选当前路径用得到的模式。可运行的 [服务清单样张](../assets/patterns.html) 演示本地筛选、数值排序、选择范围与详情；不代表真实接口或完整产品。

## 搜索与筛选

中文输入法组词期间不要据临时拼音重写结果、提交表单或触发全局快捷键；结合 `compositionstart/end` 和事件的 `isComposing`，结束后处理最终输入，且避免同一值重复发请求。输入法浏览器差异需实际覆盖，合成事件只证明代码分支。

搜索框值立即反映输入；可以对请求防抖，不能对文字回显防抖。`Escape` 的清空／关闭行为遵守所在控件模式；不在组词中抢键，不拦浏览器查找、复制粘贴和文本编辑快捷键。失焦或搜索不能突然把焦点跳到结果第一行。

区分筛选条件与显示偏好：前者决定哪些对象出现，后者决定列、密度和分组怎样呈现。活动筛选必须看得见、能逐项移除和一键恢复；“无匹配”提供清筛选，而不是用“创建第一条”假装整个集合为空。

数量说明范围：本页、当前筛选、总计、已加载不能混称总数。筛选改变后重置或夹取页码，取消过时请求；不要让页码 8 留在只有一页的新结果中。

## URL、历史与隐私

可分享、非敏感且有稳定含义的筛选、排序、分页可进 URL；弹窗开关、输入草稿和 hover 不必进 URL。邮箱、令牌、付款资料、未公开搜索词默认不进 URL、analytics 或持久存储。即便只读查询也先判断敏感性。

尊重现有路由器。连续键入通常替换当前记录或只在确认后提交状态；用户认为是一次导航的变化才新增历史条目。处理首次加载、无效参数、刷新、Back/Forward；恢复状态不能再次制造历史。不要简单把所有 `useState` 映射到查询参数。

返回列表应保留合理筛选和滚动上下文；对象已删除或权限变化时给明确恢复路径。不要把私有数据硬塞入 history state 以替代重新验证。依据见 [MDN History API](https://developer.mozilla.org/en-US/docs/Web/API/History_API/Working_with_the_History_API)；具体取舍不是 API 的强制行为。

## 表格与选择

只读比较先用原生 table、caption、表头与行标题；只有需要单元格级方向键导航或编辑时才评估 grid，不能为看起来高级而加 `role="grid"`。

可排序表头内用按钮，实际排序列设置 `aria-sort`，排序方向有可见提示。按原始类型稳定排序；同值用稳定 ID／原始顺序，未知值的位置明确且不能当零。前端只拿到一页时不能声称已对全量数据排序。

默认把全选明确标作“本页”或“本次筛选”。部分选中用原生 checkbox 的 `indeterminate` 属性；它不是 HTML 属性。选中状态按稳定对象 ID 保存，不按行号。筛选隐藏已选项时明确选择保留还是清除；样张采用筛选变化清除、仅排序保留。跨页全选必须有独立确认与数量范围，不能静默扩大。

对象名称保留可识别信息；导航用真实链接，展开详情用按钮。不要把含复选框、链接和菜单的整行包成一个按钮。行菜单在键盘焦点和触摸上可发现，不能只在 hover 出现且无替代。大表性能优化要同时验证读屏、浏览器查找、滚动恢复和选择，不默认虚拟化。

## 表单与校验

常驻标签、帮助和错误有明确关系；在提交或适当的离焦时校验，不在输入第一个字符时就斥为无效。`type`、`inputmode`、`autocomplete` 按字段语义设置；允许粘贴与密码管理器。只对明确允许的字段 trim，不静默改写密码、令牌或有意义的空格。

长表单可用错误摘要：与字段错误同文案、链接到对应字段、焦点可到达；摘要不能代替字段边上的提示。单个短表单按任务选择首错聚焦或摘要，不把 GOV.UK 的站内强制模式当所有产品的唯一方案。

网络或权限失败不是输入格式错误。失败后保留安全输入和用户进度；解决了某个字段错误再移除它的 invalid 状态，而不是任意敲键就全清。成功反馈应说明实际保存的对象和范围，不能拿本地状态变化当服务端已持久化。

## 反馈与危险操作

短暂 toast 适合低风险确认，不承载必须处理的错误或唯一恢复入口。用持久的就地状态承载失败、离线或结果未确认；更新提示不重建整张表让读屏重复读所有内容。`aria-live` 只放简短状态，不包裹整个工作区。

复制只有 Clipboard API 成功后才显示成功，拒绝时提供手动选择路径。下载链接必须指向存在的文件；上传分别呈现选中、上传中、服务端处理中、成功与失败，取消后不接受迟到回调。

可撤销低风险操作可直接执行并提供 Undo；不可逆删除、付费或权限扩大则确认对象与后果。不能无后端支持却宣称可撤销，也不能让确认按钮在异步结束后误作用于新选中的对象。跨账户的缓存、请求和草稿必须隔离。
