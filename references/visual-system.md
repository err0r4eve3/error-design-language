# 数值与材料

以下是可调整的实现起点，不要求所有项目照抄同一组尺寸和参数。所有项目统一映射到同一黑白灰 token；旧暖色或彩色界面 token 按本次修改范围迁移。保留框架与字体；不建立平行的第二套主题系统。

## 层级与色彩

| 角色 | 浅色起点 | 深色起点 | 用法 |
|---|---|---|---|
| 画布 `canvas` | `#F4F4F4` | `#141414` | 环境底色，保持安静 |
| 工作区 `workspace` | `#EDEDED` | `#1B1B1B` | 辅助区、凹入区域 |
| 内容面 `surface` | `#FFFFFF` | `#232323` | 稳定阅读与表单 |
| 强文字 `strong` | `#1C1C1C` | `#F5F5F5` | 标题、价格、关键结果 |
| 正文 `text` | `#383838` | `#DEDEDE` | 内容主体 |
| 辅助 `muted` | `#666666` | `#AAAAAA` | 元数据，仍需可读 |
| 分隔线 `line` | `#E0E0E0` | `#383838` | 非交互结构，低于文字权重 |
| 输入边界 `control-border` | `#909090` | `#808080` | 辨认输入范围 |
| 选中底 `selected` | `#EEEEEE` | `#333333` | 搭配单选、指示线，避免大块深灰 |
| 选中文字 `selected-text` | `#1C1C1C` | `#F5F5F5` | 与选中底成对 |
| 主操作 `primary` | `#262626` | `#F5F5F5` | 小面积最高操作层级 |
| 主操作文字 `on-primary` | `#FFFFFF` | `#171717` | 与主操作成对修改 |
| 次操作 `secondary` | `#FFFFFF` | `#2D2D2D` | 边界弱于主操作 |
| 次操作文字 `on-secondary` | `#303030` | `#F0F0F0` | 不继承主操作的白字 |
| 禁用底 `disabled` | `#E6E6E6` | `#303030` | 不冒充可用主操作 |
| 禁用文字 `on-disabled` | `#626262` | `#AAAAAA` | 独立颜色，不整体透明 |
| 输入文字 `input-text` | `#262626` | `#F0F0F0` | 高于 placeholder 的信息层级 |
| 占位文字 `placeholder` | `#707070` | `#AAAAAA` | 不代替常驻标签 |

按钮状态成对配置：浅色主操作 hover `#3A3A3A`、按下 `#111111`，始终白字；深色主操作 hover `#DEDEDE`、按下 `#C7C7C7`，始终 `#171717` 文字。次操作使用自己的 hover／按下背景。处理中保留原操作颜色并显示文字，真正不可用时才改为禁用组合。

不要对整个按钮应用 opacity 或亮度滤镜；它会连同文字一起改变。不要使用一个全局 hover 颜色覆盖所有按钮。跨主题切换时文字与背景应同步更新；示例按钮采用即时颜色反馈，避免只过渡背景时出现瞬间低对比。参考 [components.css](../assets/components.css) 的局部变量映射，主次操作复用结构而不串用文字色。

浮层先复用内容面，通过遮罩、位置、边界及少量阴影表达提升。没有必要为每一个容器新增颜色。品牌识别由真实图形和排版承担；状态先用文字与图标，确有安全需求的小面积语义色与普通装饰分开管理。

历史暖色与珊瑚色 UI 分支已被本次统一要求取代。博客仪器、螃蟹图形等识别元素可保留造型，界面配色优先转为灰阶；彩色内容资产与科学图例不机械去色。

## 尺寸与排版

| 内容 | 建议起点 | 判断依据 |
|---|---|---|
| 工具页标题 | 24–32px，600 | 首屏仍能看到任务与内容 |
| 分区标题 | 18–22px，600 | 与正文有差别，不抢页面标题 |
| UI 正文 | 14–16px，行高 1.5–1.7 | 依据真实中文密度调整 |
| 长文正文 | 17–18px，行高 1.75–1.9 | 使用长段落检验，不只看短样例 |
| 元数据 | 12–14px | 不靠小字承载关键状态或费用 |
| 间距 | 4、8、12、16、24、32、48px | 组内紧于组间，遵守同一节奏 |
| 工具页容器 | 1120–1280px 或按工作台延展 | 不能机械限制 IDE、表格和画布 |
| 阅读列 | 中文约 32–42em；西文约 65–75ch | `ch` 不等于汉字个数，实际长文验证 |
| 控件可见高度 | 36–44px | 桌面密度与移动触控分开考虑 |
| 移动触控目标 | 默认至少 44×44 CSS px | 是此 Skill 的易用性目标，不声称是 WCAG AA 的统一最小值 |

沿用项目字体。没有既有字体时用系统无衬线与中文回退；数字、金额和参数可用等宽数字，代码用等宽字体。衬线只用于适合的编辑性标题或品牌，不能成为所有工作台的新默认。

## 形状

| 角色 | 起点 | 例外 |
|---|---|---|
| 页面、连续窗格、表格、正文 | 0 | 既有独立阅读底板可保留合理圆角 |
| 连续行 hover／selected | 0–4px | 由列表结构决定 |
| 按钮、输入 | 6–10px | 移动原生控件、品牌控件可调整 |
| 独立内容块 | 8–12px，确有分组价值时 | 不把每个段落都变成块 |
| 菜单、popover、dialog | 12–16px | 大尺寸模态可按系统规范调整 |
| 标签、头像、独立圆形图标按钮 | 999px 或 50% | 只有形状帮助识别角色才使用 |

不要通过全局 `border-radius: 0 !important` 修复圆角过多；逐层识别语义后调整。

## 玻璃与动效

玻璃分为三个层次，共用同一套灰阶与层级：

| 材料 | 用途 | 表达 |
|---|---|---|
| 实色 | 正文、表格、代码、关键操作 | 稳定背景、细分隔线 |
| 毛玻璃 | 导航、侧栏、辅助面板 | 半透明底色、轻 blur、薄高光 |
| 液态玻璃 | 菜单、浮动工具、独立控件与对话框 | 局部曲面高光、内沿反光、克制的透射感 |

液态效果按容器边缘处理，不扭曲正文，不默认引入 WebGL／持续追踪指针的着色器。性能不足时降级为毛玻璃，再降级为实色。CSS 样张是这种材质的轻量近似，不宣称真实光学折射模拟。

- 首选实色承载文本；辅助壳层可从 82%–94% 不透明度、8–16px blur 起步，并检查真实背后内容。这里不是跨项目固定值。
- 避免在正文、大表格或嵌套层级反复 blur。移动端减少覆盖面积与模糊半径；实色 fallback 在不支持滤镜时先成立。
- 高频控件可从 120–180ms、浮层从 180–240ms 起步。优先 opacity 和小幅 transform，不用动效掩盖真实等待。
- `prefers-reduced-motion` 下保留状态但去掉位移、弹跳和非必要延迟；`prefers-reduced-transparency` 下用实色。
- CSS 示例不含品牌动效。博客、游戏或吉祥物需要另按项目语境实现。

## 可读性验收

普通文字对比度至少 4.5:1；大字号文字适用 3:1 的条件需按规范判断。必要的控件边界和状态指示相对相邻色达到 3:1；不是每条装饰分隔线都必须达到这一值。不要通过对比度达标推断整体无障碍合规。参见 [W3C 文字对比](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) 与 [非文字对比](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。

WCAG 2.2 AA 的目标尺寸规则采用 24×24 CSS px，并有间距等例外；本 Skill 默认移动端 44×44 是更宽松的触控设计目标。参见 [W3C 目标尺寸](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)。

玻璃需测合成背景；hover、selected、focus、disabled 与错误文本分别检查。关闭模糊或用更复杂内容作背景后，文字不能失去可辨识度。
