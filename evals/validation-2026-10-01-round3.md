## 实际运行

环境：Python 3.13.5、Node.js 22.16.0、Chromium 144.0.7559.96、已有 Playwright；没有安装依赖。Browser 插件不可用，采用 Playwright。首次 file 导航得到 `net::ERR_BLOCKED_BY_ADMINISTRATOR`；随后显式使用新页面的 `set_content` 加载本地 fixture，没有尝试绕过导航限制。

```sh
# 在 Skill 目录
node --test tests/*.test.cjs
git diff --check
# 在独立 relay-demo 目录，按实际位置传入 Skill
python build.py --skill-dir ../error-design-language
node --check app.js
python verify.py --chromium /usr/bin/chromium --out ./evidence
```

## 边界

页面使用固定演示对象、价格、文档示例 IP 和历史流量序列。已知总量附覆盖范围；全项目概览不随清单筛选；图表是明确独立的固定时间窗序列。新建只修改当前页面内存，刷新即恢复，不访问真实账号、支付、服务器或 API。

未验证 URL 导航、真实资源加载、Safari / Firefox、实体手机软键盘、原生输入法、操作系统剪贴板成功写入、完整读屏或全站 WCAG 合规。输入法测试为合成事件；复制测试覆盖拒绝后的恢复，不证明系统权限授予。原生模态允许焦点进入浏览器 chrome；检查的是背景页面控件不会接收 Tab，不将其描述为锁住浏览器。

本轮没有重新运行未改动的两个旧样张浏览器套件；其前两轮结果保留原日期。30 个模型场景和 plugin-eval CLI 均未执行。单个人工审阅、修订后的页面证明该实现的检查结果，不证明 Skill 的平均质量、触发率、token 收益或相对其他工具的胜率。
