## 实际运行

本地采用相关文件快照，不是完整仓库 checkout。修改前的入口、README、所用共享资产和颜色工具均按 Git blob SHA 与固定远程版本核对。只运行此次受影响的检查，不把其他未运行套件纳入本轮通过数。

环境：Node.js 22.16.0，Chromium 144.0.7559.96，环境已有 Playwright。Browser 插件未列为可用；使用现有 Playwright 与显式内存 fixture，不绕过已知导航限制。执行命令：

```sh
node --test tests/color.test.cjs tests/regions.test.cjs
DESIGN_QA_MODE=inline node tests/regions.cjs
```

浏览器命令另外设置 `PLAYWRIGHT_MODULE`、`CHROME_EXECUTABLE_PATH` 指向已有安装，`DESIGN_QA_DIR` 指向源目录外新目录。默认入口仍为 file 模式，导航失败不会自动转为通过。
